Автокликер для Windows, который находит цель на экране по картинке, а не по
координатам. Вы делаете снимок нужного элемента — кнопки, иконки, чего угодно —
и программа кликает по нему, где бы он ни оказался. Если элемент сдвинулся или
окно переехало, клик всё равно попадёт куда надо.

![Окно программы](docs/screenshot-main.png)

## Что умеет

- **Поиск по изображению** — сопоставление шаблонов через OpenCV, а не слепые
  клики по координатам.
- **Несколько целей сразу** — база целей с переключателями: каждую можно
  включить или выключить, не удаляя.
- **Снимок прямо из программы** — выделяете область экрана, она становится целью.
- **Два способа клика** — обычный курсором или напрямую в выбранное окно, чтобы
  мышь оставалась свободной для другой работы.
- **Зона сканирования** — ограничение поиска частью экрана, заметно поднимает
  скорость.
- **Лимит кликов** — остановка после заданного числа срабатываний.
- **Настраиваемые клавиши** — вместо жёстких F7 и F8 можно назначить свои,
  включая сочетания вида `ctrl+shift+r`.
- **Статистика** — сколько кликов сделано и сколько времени движок работает.
- **Отладка зрения** — окно, показывающее, что именно программа нашла на экране.
- **Русский и английский** интерфейс, язык определяется по системе.

## Для чего это

Повторяющиеся действия, где нет ни горячей клавиши, ни скрипта: прокликать
одинаковые диалоги, дождаться появления кнопки в старой программе без API,
прогнать однотипный сценарий в тестируемом приложении, автоматизировать рутину
в интерфейсе, который меняет положение элементов.

## Ответственное использование

Это инструмент автоматизации вашего собственного рабочего процесса. Не
используйте его там, где правила сервиса запрещают автоматический ввод — в
онлайн-играх это почти всегда нарушение пользовательского соглашения. Проект
для такого не предназначен и не тестировался.

## Быстрый старт

### Готовая сборка

Скачайте exe из [релизов](../../releases/latest) и запустите. Ничего
устанавливать не нужно.

### Из исходников

```bash
python -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt
```

```bash
.venv\Scripts\python.exe main.py
```

Нужен Python 3.10 или новее и Windows.

## Как пользоваться

1. **СНИМОК** — выделите на экране то, что программа должна искать. Или
   **ИМПОРТ**, если картинка уже есть файлом.
2. Цель появится в базе. Переключателем рядом её можно временно отключить.
3. **ЗАПУСК (F7)** — движок начинает сканировать экран. **СТОП (F8)** —
   останавливает. Обе клавиши работают и когда окно свёрнуто.
4. В статусной строке во время работы видно число кликов и время работы.

## Настройки

![Настройки](docs/screenshot-settings.png)

| Параметр | Что делает |
|---|---|
| Протокол ввода | `physical` двигает настоящий курсор, `background` отправляет клик прямо в окно |
| Действие | левый, правый или двойной клик |
| Чувствительность | насколько точно картинка должна совпасть: выше — строже |
| Задержка | пауза между кликами по одной и той же цели |
| Лимит кликов | остановка после N кликов, 0 — без ограничения |
| Горячие клавиши | свои клавиши запуска и остановки |
| Зона сканирования | ограничить поиск частью экрана |
| Отладка зрения | окно с тем, что видит алгоритм |

Настройки хранятся в `phantom_config.json` рядом с программой.

## Как это устроено

Программа делает снимок экрана (или заданной зоны), переводит его в оттенки
серого и ищет каждую активную цель методом `cv2.matchTemplate` с метрикой
`TM_CCOEFF_NORMED`. Все точки, где совпадение выше порога чувствительности,
считаются найденными; кликается первая из них, после чего до следующего клика
по этой цели выдерживается заданная задержка.

Режим `background` отправляет сообщения `WM_LBUTTONDOWN` и `WM_LBUTTONUP`
напрямую в окно под указанной точкой через `PostMessage`. Курсор при этом не
двигается, поэтому можно продолжать работать мышью.

## Ограничения

- Только Windows: режим `background` построен на Win32 API.
- Поиск по шаблону чувствителен к масштабу. Если разрешение экрана или масштаб
  интерфейса изменились, цели придётся переснять.
- Сопоставление идёт по оттенкам серого, так что цели, отличающиеся только
  цветом, программа не различит.
- Чем больше активных целей и чем шире зона сканирования, тем ниже частота
  проверок. Зона сканирования помогает сильнее всего.
